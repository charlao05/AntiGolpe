# Provider Gate

Nenhum provider real foi integrado.

Antes da integração, documentar:
- uso de dados;
- retenção;
- treinamento;
- residência/processamento;
- custo por análise;
- limites;
- timeout;
- fallback;
- termos de uso.

O adapter real deve implementar `LLMProvider` sem alterar o domínio do sistema.
